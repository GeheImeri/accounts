# Accounts — UI 草图与交互说明

> 对应 `mockups/index.html`（可视化版）。线框图为示意，实际用 Jetpack Compose 实现。
> 全局布局：**底部 3 个 Tab：记一笔 / 明细 / 统计**。打开 App 默认停在「记一笔」。

---

## 0. 全局导航结构

```
┌─ MainActivity（单 Activity）
│   底部导航： [➕ 记一笔] [📋 明细] [📊 统计]
│
├─ 记一笔（默认页）
├─ 明细 ──点击某笔──► 编辑弹层 / 全屏编辑页
│      └─ 筛选 / 搜索（展开）
├─ 统计 ──点分类下钻──► 该分类明细页
│
└─ 设置（记一笔页右上齿轮进入）
     ├─ 分类管理（支出 / 收入 两套）
     ├─ 账户管理 ──转账入口
     ├─ 导出 / 备份恢复
     └─ 主题 / 关于
```

---

## 1. 记一笔（默认首页）

```
┌─────────────────────────────────┐
│ [支出 | 收入]               ⚙ 设置│   ← 类型切换（默认支出），齿轮进设置
│                                 │
│           ¥ 0.00               │   ← 大号金额，点按弹数字键盘
│      备注 ________________      │   ← 可选，就地一行
│                                 │
│  ── 选个分类 · 点选即记好 ──      │
│    🍜餐饮  🚇交通  🛒购物  🏠居住   │
│    🧻日用  🎮娱乐  💊医疗  🎁人情   │
│    📚学习  ✈️旅行  ⬜其他  ＋更多…  │   ← 4 列大宫格，点分类 = 保存
│                                 │
│  钱包: 现金 ▾   今天 12:30 ▾      │   ← 账户、时间可改
│  ── 最近金额 ──────────────────   │
│   [15]  [23.5]  [6]  [300]      │   ← 常用金额 chips（P1）
│  ── 我的模板 ──────────────────   │
│   ⭐早餐 ¥8   ⭐地铁 ¥6   ＋      │   ← 一键记账模板（P1）
│                                 │
│            [ 保 存 ]             │   ← 兜底按钮（金额>0 可点）
└─────────────────────────────────┘
```

### 交互要点

1. **打开即记账**：无启动页，默认「支出」，金额输入框自动聚焦弹数字键盘
2. **点分类即保存**：金额 > 0 时点分类直接存（省一次点击）→ 进入**连续记账态**（金额清空、分类账户保留，轻提示"已记 · 继续录入"）
3. 类型切换后分类宫格切换为收入分类（工资/奖金/退款…）
4. 金额格式化：千分位 + 两位小数（如 1,234.50）
5. 记完一笔短暂高亮反馈（不打断连续录入）
6. 主色块大、可点区域 ≥ 48dp，单手可操作
7. **时间跟随系统（Q1）**："今天 12:30"实时取自系统时钟，每次进入页面刷新；点保存才固化时间戳，之后改系统时间不影响已记流水

## 2. 明细

```
┌─────────────────────────────────┐
│ 明细                ‹ 11月 ›  ⚙ │   ← 月份切换
│  本月支出 ¥2,345   收入 ¥9,000   │   ← 聚合条
│  🔍 搜索备注…        [筛选 ▾]    │
│                                 │
│ ── 11月12日 · 支出 ¥47.50 ────── │
│  🍜 午餐 · 现金 · 和同事     −23.50│
│  ☕ 咖啡 · 现金               −18.00│
│  🚇 地铁 · 微信零钱            −6.00│
│ ── 11月11日 · 支出 ¥1,206 ────── │
│  🏠 房租 · 储蓄卡 · 11月房租 −1,200.00│
│  🎁 红包 · 微信零钱          ＋200.00│  ← 收入行绿色带＋
│                                 │
└─────────────────────────────────┘
     [➕ 记一笔]  [📋 明细]  [📊 统计]
```

### 交互要点

1. 按日分组；每组右侧显示当日小计；日期行可点折叠/展开
2. 点击任意一笔 → 弹出编辑（或全屏页）：改 金额/分类/账户/时间/备注，可删除、**再次记账**
3. **再次记账**：复制该笔的分类+金额+账户，时间置为"现在"，回车即存（解决"昨天也吃了这个"）
4. 左滑快速删除（带撤销提示，P1）
5. 筛选：类型/分类/账户/区间组合，结果实时刷新；搜索框支持中文分词模糊匹配
6. 收入金额显示 ＋ 与绿色；支出 − 用主文字色（可按你喜好调整）

## 3. 统计（默认本月）

```
┌─────────────────────────────────┐
│ 统计                  [本月 ▾]   │   ← 本月/上月/今年/自定义
│                                 │
│   支出 ¥2,345 ▼ 8%  收入 ¥9,000  │   ← 环比上月
│                                 │
│        ╭───────────╮            │
│       │   支出构成  │            │   ← 环形图（Canvas）
│       │  餐饮 35%  │            │      中心为占比最大项
│        ╰───────────╯            │
│                                 │
│  ── 分类排行（支出）──────────    │
│  🍜 餐饮    ¥820  35% ████████░ │   ← 点击下钻
│  🏠 居住    ¥1,200 51% ████████░ │      （示例顺序按金额排）
│  🛒 购物    ¥180   8% ███░░░░░░  │
│  🚇 交通    ¥145   6% ██░░░░░░░  │
│                                 │
│  ── 近 6 月支出趋势 ──────────    │
│   ▂▄▆▅▇█  (柱状/折线)            │
│                                 │
└─────────────────────────────────┘
     [➕ 记一笔]  [📋 明细]  [📊 统计]
```

### 交互要点

1. 默认「本月」，页首切换；自定义区间弹起止日期选择
2. 总览卡显示 支出/收入/结余；支出带环比（▼红涨 ▲绿跌，可选配色习惯）
3. 环形图点击扇区 = 选中该分类（排行榜联动高亮）
4. 排行榜点击 → 下钻页：该分类该周期的 逐日小计 + 逐笔列表
5. 趋势图：月度视角给近 6/12 个月；柱状可切收入对比（P1）
6. 统计数字全部实时聚合（见需求文档第 6 节），与明细永远一致
7. （可选开关，Q3）总览卡第 3 项可在「本期结余 / 累计结余（含上月结转）」间切换，开关在设置里，默认"本期结余"

## 4. 分类管理（设置 → 分类管理）

```
┌─────────────────────────────────┐
│ ‹ 分类管理              ＋ 新增  │
│ [支出]  [收入]                  │
│                                 │
│  拖≡ 🍜 餐饮        ●绿   启用  │   ← 拖动排序
│  拖≡ 🚇 交通        ●蓝   启用  │
│  拖≡ 🛒 购物        ●橙   启用  │
│  拖≡ 🏠 居住        ●紫   启用  │
│  拖≡ 🧻 日用        ●青   停用  │   ← 停用灰显（不真删）
│                                 │
│ ──────────────────────────────  │
│ 提示：分类只可停用不可删除，       │
│ 历史流水不会被清空。              │
└─────────────────────────────────┘
```

### 交互要点

1. 编辑分类：改名 / 换 emoji / 换颜色（色板弹层）
2. 停用后：记账页不显示、历史照常展示、统计照常归组
3. 新增分类可自定义 emoji 图标（键盘表情即可输入）

```
账户列表：
┌─────────────────────────────────┐
│ ‹ 账户管理              ＋ 新增  │
│  现金      初始 ¥0   余额 ¥1,250 │
│  储蓄卡    初始 ¥0   余额 ¥8,000 │
│  支付宝    …                     │
│  微信零钱  …                     │
│  ──────────────────────────────  │
│         [ 转账 ]                │   ← 进入转账页

转账页：
┌─────────────────────────────────┐
│ ‹ 转账                          │
│  从: 现金 ▾   到: 储蓄卡 ▾      │
```

### 交互要点

1. 余额 = 初始余额 + 转入 − 转出 + 收入 − 支出（实时推算）
2. 转账产生两条关联记录（A 转出 / B 转入），明细中以同一组显示；不出现于统计

## 7. 视觉规范（草案）

| 项 | 规范 |
|---|---|
| 布局 | 8dp 网格；底部导航高 56dp；内容左右边距 16dp |
| 金额 | 大字号（记一笔页 40sp 以上）、`tabular-nums`（数字等宽对齐） |
| 颜色 | 背景浅色 #F7F7F5 / 深色 #121212（跟随系统）；文字主 #1A1A1A；强调色蓝 #3D6FF2（或绿 #0FA36B，待定）；收入绿 #0E9F6E；警示红 #D64545 |
| 分类图标 | emoji（🍜🚇🛒🏠…），色块底 + 圆形/圆角矩形 |
| 字体 | 系统默认字体（无自定义字体，保体积） |
| 动效 | 克制：仅页面切换淡入淡出与保存轻反馈，无装饰动画 |
| 触控 | 可点区域 ≥ 48dp；单手可达（底部操作集中） |

## 8. 交互流程速查（验收时可对照）

```
记固定支出（模板）: 打开App → 点⭐早餐 → 完成（2 次点击）
记随机支出:         打开App → 输23.5 → 点餐饮 → 完成（3 次点击）
批量记小票:         打开App → 23.5/餐饮 → 12/交通 → …（连续记账态）
发工资:             打开App → 切收入 → 9000 → 点工资（3 次）
月末看账:           打开App → 切统计Tab（1 次点击）
查上月餐饮:         统计 → 上月 → 点餐饮分类
退款:               记一笔 → 切收入 → 30 → 点退款分类
转账:               设置 → 账户管理 → 转账 → 填金额 → 确认
```
