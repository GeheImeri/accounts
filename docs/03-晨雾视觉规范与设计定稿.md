# Accounts · 视觉规范与设计定稿（E · 晨雾）

> 状态：**已定稿**（v1.0）· 采用第二轮风格 Demo 的 **E · 晨雾（浅色玻璃拟态）**
> 对应 Demo：`mockups/styles/style-e-mist.html`（7 屏）
> 实现载体：Jetpack Compose（`android/` 工程内 `ui/theme/`）

---

## 1. 设计语言一句话

**淡紫·天蓝·薄粉的晨雾渐变 + 磨砂玻璃卡片 + 纯圆无文字底栏**；柔和、轻盈、大留白；无图案图标（分类=渐变色片），信息靠文字与色块承载。

## 2. 色彩令牌（浅色，默认）

| 令牌 | 值 | 用途 |

| glass | 白 62% 透明度 + blur | 卡片/输入条/底栏（磨砂玻璃） |
| ink / textPrimary | `#3F4257` | 主文字 |
| ink2 / textSecondary | `#9A9DB3` | 次要文字 |
| accent 紫 | `#8B7CF6` | 主强调（选中、CTA） |
| accent 蓝 | `#5FB4FF` | 渐变第二色（CTA 渐变 `#8B7CF6→#5FB4FF`） |
| income | `#2FC98A` | 收入 / ＋号 |
| expense | `#FF7D9C` | 支出（细线条/负值语境，主色仍以 ink 为主） |
| hairline | `#EEEBF6` | 分割线 |

## 3. 形状与玻璃

| 元素 | 规范 |
|---|---|
| 分类色片 / 卡片 | 圆角 20–24dp，白 62% 玻璃 + 白 95% 细描边 + 柔和投影（不透明阴影 10–16%） |
| 按钮（保存/CTA） | 胶囊 999dp，紫→蓝渐变，投影带色 35% |
| 记录行 | 无图标、无圆点，细分割线（可空） |
| 单选圆钮 | 21dp，选中内芯渐变 |
| 屏幕 | 内容区与系统栏之间 16dp+ 留白 |

## 4. 间距与排版

- 网格 4dp 基准；页面左右 16dp；区块间 18–24dp（**纵向舒展**优先，避免内容堆积在中上）
- 金额大字号：44–54sp 粗体（`tabular-nums` 数字等宽对齐），单位 ¥ 小号
- 区块小标题：11.5sp，ink2
- 首页记账路径：金额 → 点色片分类即保存（连续记账态）

## 5. 页面清单（7 屏 + 手势）

| # | 页面 | 要点 |
|---|---|---|
| 1 | 记一笔（默认 Tab） | 支出/收入段选、大金额、备注；分类色片 **8 个固定**（pinned）；钱包/时间行无图标；最近金额、模板（无文字提示，长按可删/改） |
| 2 | 明细 | 中间月份**可点跳年/月/日**；行无图标；搜索无放大镜 |
| 3 | 统计 | **设置入口（滑杆图标）在"本月"左侧**；排行>4 可"展开全部" |
| 4 | 设置 | 分类管理/账户管理/主题/默认账户/连续记账/导出备份恢复 |
| 5 | 分类管理 | 支出/收入页签；拖拽排序；"首页/仅统计"标记（首页固定 8 个）；点行改图标/颜色/名称 |
| 6 | 账户管理 | 余额实时（初始±收支±转账）；新增账户；转账入口（**转账不计收支**） |
| 7 | 主题 | 跟随系统/浅色/深色（日☀/月☾仅此处使用） |

手势约定：分类网格长按=编辑（首页）；最近金额/模板**长按删除**；分类列表**拖动手柄排序**。

## 6. 图标策略

- 应用内导航/按钮用**线性描边图标**（记一笔 ＋ / 明细 ☰ / 统计 柱状 / 设置=滑杆调节器，**非齿轮非太阳**）
- 分类**无图案图标**，颜色色片 + 名称承载语义（收入/支出两套）
- 日/夜图标（☀/☾）仅出现在「主题」选择页

## 7. 已定稿的关键交互决策（回放）

1. 首页日期时间跟随系统：显示层实时刷新，保存瞬间固化时间戳（改系统时间不影响已记数据）
2. 跨月结余：设置内开关，默认关；开启后统计总览第三卡 = 期初结余 + 本期结余 = 累计结余（历史累计收支）
3. 金额一律以「分」存 Long；转账独立 Transfer 表、不计收支
4. 无 INTERNET 权限；数据仅存本机；导出 CSV（UTF-8 BOM）/JSON + 备份恢复
5. 分类不可真删（停用），历史流水不悬空
