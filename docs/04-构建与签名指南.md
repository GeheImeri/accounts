# Accounts · 构建与签名指南

## 1. 两种构建方式

### 方式 A：GitHub Actions（推荐，本机零安装）
把整个 `jianji/` 目录推成 GitHub 仓库的 `main` 分支即可：

```bash
cd jianji
git init
git add .
git commit -m "init: Accounts v0.1.0 骨架（晨雾主题 + Room + 三主屏）"
git branch -M main
git remote add origin https://github.com/<你的用户名>/jianji.git
git push -u origin main
```

推送后到仓库 **Actions** 页查看 `build-apk` 工作流；构建完成后在对应 run 的 **Artifacts** 下载 `jianji-apk`，解压得到 `app-release.apk`。

> 手动触发：仓库 Actions → build-apk → Run workflow。

### 方式 B：本机 Android Studio（可选）
1. Android Studio → Open → 选择 `F:\deepseek harness\jianji`
2. 等待 Gradle Sync（首次会下载 Gradle 8.9 与依赖）
3. Build → Build App Bundle(s)/APK(s) → Build APK(s)
4. 产物：`app/build/outputs/apk/debug/app-debug.apk`

命令行（本机有 JDK 17 时）：
```bash
./gradlew.bat assembleDebug    # Windows
./gradlew assembleDebug        # macOS / Linux
```

## 2. 安装到手机（无需开发者模式）

1. 手机浏览器下载 APK（GitHub 或传输到手机）
2. 打开时允许"安装未知来源应用"（各 ROM 提示略有差异）
3. 完成后桌面出现「Accounts」图标

> 国内网络下载 GitHub 慢时：电脑下载 APK → 微信文件传输助手 / 数据线传到手机安装。

## 3. 签名（重要：覆盖升级不丢数据）

- **debug 签名**：每次 CI 都是全新环境 → 签名每次不同。第一次安装没问题，但**下次覆盖安装会提示"签名不一致"，只能卸载重装（会丢数据）**。
- **解决方案：固定 release 签名**，一次性配置：

```bash
# 本机任选目录执行（需 JDK keytool）
keytool -genkeypair -v \
  -keystore jianji.jks -alias jianji \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -storepass 你的密码 -keypass 你的密码 \
  -dname "CN=Jianji, OU=Personal, O=Jianji, L=City, ST=State, C=CN"
```

```powershell
# 转 base64 单行文本（Windows PowerShell）
[Convert]::ToBase64String([IO.File]::ReadAllBytes("jianji.jks")) | Set-Content -NoNewline keystore.b64
```

GitHub 仓库 → Settings → Secrets and variables → Actions 添加四个 Secret：

| Secret | 值 |
|---|---|
| `ANDROID_KEYSTORE_B64` | keystore.b64 全文 |
| `ANDROID_KEYSTORE_PASS` | storepass 密码 |
| `ANDROID_KEY_ALIAS` | `jianji` |
| `ANDROID_KEY_PASS` | keypass 密码 |

之后每次 push 自动产出**同一签名**的 release APK，覆盖安装升级不再丢数据。
（workflow 会先把 `ANDROID_KEYSTORE_B64` 解码成临时 keystore 文件再交给 Gradle，构建脚本无需处理 Base64。）

> keystore 与 b64 文件**不要提交进仓库**（`.gitignore` 已排除 `*.keystore`）。

## 4. 升级流程（日常）

1. 本地改代码（或 Codespaces）
2. `git push` → Actions 自动构建
3. 手机下载新 APK 直接覆盖安装 → 数据保留

## 5. 本地数据

- App 数据存于 `Room(SQLite) jianji.db`，全部在本机；未声明任何网络权限。
- 换机/刷机前请先在「设置」中完成导出（导出/备份功能在 v0.2 迭代中开放）。
